# Junnuo Lin Academic Homepage

Static bilingual academic homepage for [jnlin-re.github.io](https://jnlin-re.github.io/).

## Local preview

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Then open `http://127.0.0.1:4173/`.

## Files

- `index.html`: semantic page content in Chinese and English
- `styles.css`: desktop and mobile layouts
- `script.js`: language switcher, mobile navigation, and active-section state
- `assets/avatar.png`: public profile avatar
- `assets/avatar-cutout.png`: transparent profile cutout used by the page
- `assets/forest-scene.webp`: compressed forest background from Unsplash

The first release intentionally has no resume download. Phone numbers, birth dates, student identifiers, identity documents, and private repository content must not be added.

## Optional scene asset

The forest photograph is loaded locally from [Unsplash](https://unsplash.com/photos/trees-in-forest-with-sun-rays-2Hzmz15wGik) under the Unsplash License and receives a cool, misty color treatment in CSS. The animated literary motifs are original inline SVG and CSS compositions. Do not reuse copyrighted character art or images from another personal website.
